# Site da Igreja Batista Missionária em Águas Compridas

Este projeto usa Eleventy (gerador de site) + Decap CMS (painel de edição sem código).

## Como publicar (uma vez)
1. Suba esta pasta inteira para um repositório no GitHub.
2. No Netlify: "Add new site > Import an existing project > Deploy with GitHub" e selecione o repositório.
   O Netlify já vai ler o arquivo `netlify.toml` e configurar tudo sozinho.
3. Ative "Identity" no painel do Netlify (aba Identity > Enable Identity).
4. Em Identity > Services > Git Gateway, clique em "Enable Git Gateway".
5. Em Identity > Invite users, convide o e-mail de quem vai editar o site.
6. Acesse seusite.netlify.app/admin para editar.

Veja o guia completo enviado pelo Claude para o passo a passo detalhado.
